      TV can't connect?

      1. Allow the Windows Firewall prompt. On first run Windows asks whether to allow Kino Server on your network — it must be allowed on Private networks. If you dismissed it, remove the rule in Windows Defender Firewall and restart this app to be asked again.
      2. Same network. Both devices must be on the same router. A 2.4 GHz and 5 GHz band on the same router is fine; a separate "Guest" network is not.
      3. Client isolation. Some mesh routers block device-to-device traffic. Look for "AP isolation" or "Client isolation" in your router settings and turn it off.
